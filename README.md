📘 중학교 교육과정 컨설팅 시스템 구축 및 운영 매뉴얼
본 매뉴얼은 구글 앱스 스크립트(Google Apps Script)를 활용하여 별도의 서버 비용 없이 구글 시트와 구글 드라이브만으로 작동하는 웹 기반 컨설팅 입력 시스템을 구축하고 운영하는 방법을 안내합니다.

📋 목차
사전 준비 (구글 시트 및 드라이브 폴더 생성)

앱스 스크립트(GAS) 코드 설정

초기 배포 및 권한 승인 (매우 중요)

코드 수정 시 재배포 방법

사용자 및 관리자 페이지 접속 방법

주요 기능 안내

1. 사전 준비
데이터가 저장될 구글 시트와 이미지가 저장될 구글 드라이브 폴더를 준비하는 단계입니다.

1) 구글 드라이브 폴더 생성 및 ID 복사
구글 드라이브에 접속하여 새 폴더를 생성합니다. (예: 컨설팅 이미지 모음)

생성한 폴더 안으로 들어갑니다.

인터넷 주소창의 URL을 확인합니다.

예시: [https://drive.google.com/drive/folders/1EbWiQrkiHadHAm_aw0vZY5i8xmAndZrD](https://drive.google.com/drive/folders/1EbWiQrkiHadHAm_aw0vZY5i8xmAndZrD)

folders/ 뒤에 있는 복잡한 영문/숫자 조합이 이 폴더의 ID입니다. 이를 복사해 둡니다.

2) 구글 시트 생성
구글 드라이브에서 새 구글 스프레드시트를 생성합니다.

1행(첫 번째 줄)에 아래와 같이 헤더(제목)를 입력해 두면 관리가 편합니다.

A열: 제출일시

B열: 위원명

C열: 학교명

D열: 학년

E열: 구분

F열: 검토내용

G열: 첨부사진

2. 앱스 스크립트(GAS) 코드 설정
생성한 구글 시트와 웹 페이지를 연결하는 코드를 입력하는 단계입니다.

방금 만든 구글 시트 상단 메뉴에서 [확장 프로그램] > [Apps Script]를 클릭합니다.

새 탭으로 편집기가 열리면, 총 3개의 파일을 만들어야 합니다.

파일 ① : Code.gs (백엔드 로직)
기본으로 생성되어 있는 Code.gs 파일을 클릭합니다.

기존 내용을 모두 지우고, 백엔드 코드(Code.gs)를 붙여넣습니다.

코드 중반부의 var folderId = "이곳에_폴더_ID_입력"; 부분을 찾아 1단계에서 복사해 둔 폴더 ID로 변경합니다.

파일 ② : Index.html (사용자 입력 화면)
편집기 왼쪽 파일 목록 위의 + (파일 추가) 버튼을 누르고 HTML을 선택합니다.

파일 이름을 Index 로 입력합니다. (대소문자 구분에 주의하세요)

사용자용 프론트엔드 코드(Index.html)를 모두 붙여넣습니다.

파일 ③ : Admin.html (관리자 대시보드 화면)
다시 + (파일 추가) 버튼을 누르고 HTML을 선택합니다.

파일 이름을 Admin 으로 입력합니다.

관리자용 프론트엔드 코드(Admin.html)를 모두 붙여넣습니다.

상단의 💾 (프로젝트 저장) 버튼을 누릅니다.

3. 초기 배포 및 권한 승인 (매우 중요)
작성한 코드를 실제 인터넷에서 접속할 수 있는 웹사이트(웹 앱)로 만드는 과정입니다.

편집기 우측 상단의 파란색 [배포] 버튼을 누르고 [새 배포]를 클릭합니다.

톱니바퀴(⚙️) 아이콘을 눌러 [웹 앱(Web App)]을 선택합니다.

설정값을 반드시 아래와 같이 지정합니다.

실행할 사용자: 나 (소유자 계정)

액세스 권한이 있는 사용자: 모든 사용자 (Anyone)

[배포] 버튼을 클릭합니다.

[접근 승인(Authorize Access)] 창이 뜹니다.

본인의 구글 계정을 선택합니다.

"Google에서 확인하지 않은 앱" 경고가 뜨면 좌측 하단의 [고급]을 누릅니다.

[~ (안전하지 않음)으로 이동]을 클릭합니다.

[허용]을 클릭합니다.

완료되면 웹 앱 URL이 발급됩니다. 이 주소가 컨설팅 위원들에게 공유할 실제 접속 주소입니다.

4. 코드 수정 시 재배포 방법
🚨 가장 많이 하는 실수! 앱스 스크립트는 코드를 수정하고 저장(💾)만 한다고 해서 실제 URL에 반영되지 않습니다. 코드를 수정한 후에는 반드시 아래 과정을 거쳐야 업데이트가 적용됩니다.

우측 상단의 파란색 [배포] 버튼을 누르고 [배포 관리]를 클릭합니다.

기존 배포 목록 우측 상단의 ✏️ (연필 아이콘: 수정)을 클릭합니다.

버전(Version) 드롭다운을 클릭하고 가장 위에 있는 [새 버전]을 선택합니다.

하단의 [배포] 버튼을 클릭합니다.

5. 사용자 및 관리자 페이지 접속 방법
1) 일반 사용자 (컨설팅 위원) 접속
3단계에서 발급받은 기본 웹 앱 URL을 그대로 클릭하여 접속합니다.

예시: [https://script.google.com/macros/s/ABCDEFG.../exec](https://script.google.com/macros/s/ABCDEFG.../exec)

2) 최고 관리자 접속 (비밀 URL)
기본 웹 앱 URL의 맨 끝에 ?mode=admin 을 덧붙여서 접속합니다.

예시: [https://script.google.com/macros/s/ABCDEFG.../exec?mode=admin](https://script.google.com/macros/s/ABCDEFG.../exec?mode=admin)

이 주소는 관리자만 북마크(즐겨찾기) 해두고 사용합니다.

6. 주요 기능 안내
👤 일반 사용자 페이지 기능
캡처 이미지 붙여넣기: 이미지 첨부 시 파일 선택뿐만 아니라, 텍스트 입력창을 클릭하고 Ctrl + V를 누르면 클립보드에 복사된 캡처 이미지가 즉시 첨부됩니다.

불러오기 및 덮어쓰기: '위원명'과 '학교명'을 입력하고 [시트에서 불러오기]를 누르면 과거 제출 내역을 불러옵니다. 내용을 수정한 뒤 다시 제출하면, 기존 데이터와 구글 드라이브에 있던 옛날 사진을 자동으로 삭제하고 새 내용으로 덮어씁니다. (중복 방지)

👑 관리자 대시보드 기능
실시간 검색: 검색창에 학교명, 위원명 등을 입력하면 즉시 필터링됩니다.

현황판: 각 학년별로 내용이 등록된 갯수(1개면 ✔, 2개 이상이면 n개)가 직관적으로 표시됩니다.

미리보기: [미리보기] 또는 [일괄 보기] 버튼을 통해 위원명이 제외된 '학교' 중심의 컨설팅 내용만 모아서 볼 수 있습니다.

PDF 일괄 다운로드(ZIP 압축):

[전체 PDF 다운로드] 버튼을 누르면 서버에서 고화질 원본 이미지를 추출합니다.

학교별로 컨설팅 결과 PDF를 한 장씩 생성한 후, 이를 하나의 ZIP 압축 파일로 묶어서 다운로드해 줍니다.
