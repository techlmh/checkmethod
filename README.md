지금까지 추가된 **관리자 페이지 필터/정렬/ZIP 다운로드 기능**과 **학교 담당자용 나이스(NEIS) 조회 및 반영 결과 입력/PDF 다운로드 기능**을 모두 포함하여, 새로운 담당자가 시스템을 완벽하게 이해하고 세팅할 수 있도록 **최종 통합 매뉴얼**을 작성해 드립니다.

## 1. 시스템 전체 구조 및 접속 URL 안내

이 시스템은 **단 1개의 웹 앱 주소(URL)** 로 동작하며, 주소 끝에 붙는 명령어(`파라미터`)에 따라 3가지 모드로 분기됩니다.

| 대상자 | 역할 | 접속 주소 형식 |
| --- | --- | --- |
| **컨설팅 위원** | 검토 의견 입력 및 이미지 첨부 | `[https://script.google.com/.../exec](https://script.google.com/.../exec)` (기본 주소) |
| **최고 관리자** | 전체 현황 조회, 정렬/필터, ZIP 일괄 다운로드 | 기본 주소 끝에 **`?mode=admin`** 추가 |
| **학교 담당자** | NEIS 번호 조회, 반영 결과 제출, PDF 다운로드 | 기본 주소 끝에 **`?mode=school`** 추가 |

## 2. 사전 준비 (구글 시트 및 드라이브 세팅)

### 1) 첨부 이미지 저장용 구글 드라이브 폴더

1. 구글 드라이브에 컨설팅 이미지가 모일 **새 폴더**를 생성합니다.
2. 폴더로 들어간 뒤 인터넷 주소창에서 ID를 복사해 둡니다.
* 예: `[https://drive.google.com/drive/folders/](https://drive.google.com/drive/folders/)`**`1EbWiQrkiHadHAm_aw0vZY5i8xmAndZrD`** (굵은 글씨 부분)



### 2) 데이터 저장용 구글 시트 생성 및 구성

구글 스프레드시트를 새로 만들고, **반드시 아래와 같이 2개의 탭(시트)** 으로 구성해야 합니다.

* **첫 번째 탭 (기본 시트, 이름 무관): 컨설팅 데이터가 쌓이는 곳**
* 1행(헤더)을 다음과 같이 작성해두면 관리가 편합니다.
* A열: 제출일시 / B열: 위원명 / C열: 학교명 / D열: 학년 / E열: 구분 / F열: 검토내용 / G열: 첨부사진(URL) / **H열: 학교담당자명 / I열: 반영결과 / J열: 반영제출일시**


* **두 번째 탭 (이름: `학교코드`): 학교 전용 로그인 데이터베이스**
* 하단 `+` 버튼을 눌러 새 시트를 만들고 이름을 **`학교코드`** 로 정확히 변경합니다.
* A열에는 **나이스번호**, B열에는 **학교명**을 입력해 둡니다. (예: `S0100001` / `가나중학교`)

## 3. 앱스 스크립트(GAS) 코드 등록

1. 설정한 구글 시트 상단 메뉴에서 [확장 프로그램] > [Apps Script]를 클릭합니다.
2. 편집기가 열리면 좌측 `+` (파일 추가) 버튼을 이용해 **총 4개의 파일**을 생성하고 코드를 붙여넣습니다.

* **① `Code.gs` (스크립트 파일)**
* 백엔드 처리(저장, 조회, 삭제, PDF 이미지 변환)를 담당합니다.
* 코드 내에 `var folderId = "폴더아이디";` 부분에 2-1)에서 복사한 **구글 드라이브 폴더 ID**가 정확히 들어가 있는지 확인합니다.


* **② `Index.html` (HTML 파일)**
* 컨설팅 위원용 입력 화면입니다. (대소문자 구분에 주의하여 파일명 생성)


* **③ `Admin.html` (HTML 파일)**
* 관리자용 전체 조회 및 ZIP 다운로드 대시보드 화면입니다.


* **④ `School.html` (HTML 파일)**
* 학교 담당자용 나이스 번호 조회 및 반영결과 입력 화면입니다.

## 4. 배포 및 권한 승인 (매우 중요)

코드를 모두 넣었다면 웹사이트 링크를 생성해야 합니다.

1. 우측 상단의 파란색 [배포] > [새 배포]를 클릭합니다.
2. 톱니바퀴(⚙️) 아이콘을 눌러 [웹 앱(Web App)]을 선택합니다.
3. 설정값 지정:
* **실행할 사용자:** `나 (소유자 계정)`
* **액세스 권한이 있는 사용자:** `모든 사용자 (Anyone)`


4. **[배포]** 버튼을 클릭합니다.
5. **[접근 승인(Authorize Access)]** 창이 뜹니다.
* 계정 선택 ➔ 좌측 하단 **[고급]** 클릭 ➔ **[~ (안전하지 않음)으로 이동]** 클릭 ➔ **[허용]** 클릭


6. 완료 시 발급되는 **웹 앱 URL**을 복사합니다.

## 5. 코드 수정 시 재배포 방법

🚨 **주의사항:** 코드를 수정하고 💾(저장)만 누르면 실제 사용자 화면에는 반영되지 않습니다. 반드시 아래 과정을 거쳐야 업데이트됩니다.

1. 우측 상단 파란색 **[배포] > [배포 관리]** 클릭
2. 기존 배포 목록 우측 상단의 ✏️ **(연필 아이콘: 수정)** 클릭
3. **버전(Version)** 드롭다운을 클릭하여 **[새 버전]** 선택
4. 하단의 **[배포]** 버튼 클릭

## 6. 화면별 주요 기능 및 사용법 안내

### 👤 1. 컨설팅 위원 화면 (기본 URL)

* **스마트 첨부:** 이미지 파일 선택 버튼 외에도, 텍스트 입력창에서 캡처한 이미지를 **`Ctrl + V`** 로 바로 붙여넣을 수 있습니다.
* **수정 및 덮어쓰기:** '위원명'과 '학교명'을 넣고 `[시트에서 불러오기]`를 누르면 과거 제출 내역을 가져옵니다. 수정 후 다시 제출하면, **기존 시트 데이터와 구글 드라이브의 옛날 사진이 자동으로 영구 삭제(휴지통 이동)** 되고 새 내용으로 깔끔하게 덮어써집니다.

### 👑 2. 최고 관리자 대시보드 (`?mode=admin`)

* **정렬 및 통계:** 화면 진입 시 **위원명 가나다순 ➔ 학교명 가나다순**으로 표가 자동 정렬됩니다. 학년별 등록 갯수가 직관적으로 표시(✔ 또는 N개)됩니다.
* **스마트 필터링:** 좌측 상단 드롭다운에서 특정 '위원명'을 선택하면 해당 위원의 데이터만 추려집니다.
* **일괄 ZIP 다운로드:** 필터링된 상태에서 `[📥 화면 조회 내역 PDF 다운로드]`를 누르면, 각 학교별 컨설팅 결과가 PDF 파일로 1장씩 자동 생성됩니다. 생성된 PDF들은 **각 '위원명'으로 된 폴더로 나뉘어 하나의 ZIP 파일로 압축**되어 컴퓨터에 다운로드됩니다.

### 🏫 3. 학교 담당자 화면 (`?mode=school`)

* **나이스 번호 조회 보안:** 배포된 URL로 접속하여 '학교코드' 탭에 등록된 우리 학교의 나이스(NEIS) 번호를 입력해야만 컨설팅 내용을 볼 수 있습니다.
* **반영결과 입력 및 PDF 보관:** 컨설팅 의견을 확인하고, 우측 칸에 반영 여부 및 조치사항을 작성합니다. 미리보기 화면에서 `[📥 PDF 다운로드(보관용)]`을 누르면 제출 전/후 언제든 결과보고서 형태의 PDF를 학교 PC에 저장할 수 있습니다.
* **제출 연동:** 최종 제출을 누르면, 구글 시트의 해당 학교 컨설팅 내역 우측(H, I, J열)에 담당자 이름과 반영 결과가 실시간으로 채워집니다.
