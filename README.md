# 🏫 중학교 교육과정 컨설팅 및 반영 결과 통합 관리 시스템

Google Apps Script(GAS)를 활용하여 구축된 **웹 기반 컨설팅 의견 작성 및 학교 반영 결과 수합 시스템**입니다.
별도의 유료 서버나 데이터베이스 없이 **Google Sheets**와 **Google Drive**만으로 모든 데이터와 이미지를 처리하며, 사용자 역할에 따라 하나의 웹 앱(Web App) 주소에서 4가지 화면으로 분기되어 작동합니다.

---

## ✨ 주요 기능

### 1. 👤 컨설팅 위원용 (입력 및 제출)
* **스마트 이미지 첨부**: 파일 업로드뿐만 아니라 입력창에 캡처 이미지 붙여넣기(`Ctrl+V`) 지원
* **동적 입력 폼**: 1학년, 2학년, 3학년, 학년전체 등 원하는 학년별로 '수정' 또는 '검토의견' 폼 무한 추가 가능
* **수정 및 덮어쓰기**: 기존 제출 내역을 불러와서 수정 후 제출 시, 기존 데이터와 구글 드라이브 원본 이미지를 자동 삭제(휴지통 이동)하여 중복 방지

### 2. 🏫 학교 담당자용 (조회 및 반영)
* **NEIS 번호 보안 로그인**: 사전에 등록된 나이스 번호를 입력해야만 자교의 컨설팅 내용 열람 가능
* **반영 결과 직접 입력**: 컨설팅 위원의 의견을 확인하고 옆 칸에 즉시 학교 측 조치사항 입력 및 제출 가능
* **개별 PDF 다운로드**: 학교 자체 보관용으로 컨설팅 내용과 반영 결과가 합쳐진 표를 PDF로 즉시 변환하여 다운로드 지원

### 3. 👑 최고 관리자용 (대시보드 2종)
* **컨설팅 제출 내역 대시보드 (`?mode=admin`)**
  * 위원별/학교별 실시간 필터링 및 가나다순 정렬 기능
  * 조회된(필터링된) 학교들의 컨설팅 결과만 묶어 **위원명 폴더별로 분리된 ZIP 파일로 일괄 PDF 다운로드** 기능 (html2pdf.js + JSZip 활용)
* **학교 반영 현황 대시보드 (`?mode=admin_school`)**
  * 각 학교가 피드백을 작성했는지 학년별로 상태(미작성/부분완료/완료) 컬러 코딩 제공
  * 클릭 한 번으로 학교 측 피드백 상세 조회 및 인쇄 가능
  * 두 관리자 대시보드 간 원클릭 탭 이동 기능 제공

## 🛠 기술 스택 (Tech Stack)
* **Backend**: Google Apps Script (JavaScript)
* **Frontend**: HTML5, CSS3, Vanilla JavaScript
* **Database & Storage**: Google Sheets, Google Drive
* **Libraries**: `html2pdf.js` (PDF 변환), `JSZip` (ZIP 압축), `FileSaver.js` (파일 저장)

---

## 📁 파일 구조 (File Structure)
* `Code.gs`: 백엔드 로직 (데이터 CRUD, Google Drive API 통신, URL 파라미터 라우팅)
* `Index.html`: 컨설팅 위원 의견 입력용 웹 페이지
* `Admin.html`: 관리자용 컨설팅 내역 조회 및 ZIP 다운로드 대시보드
* `AdminSchool.html`: 관리자용 학교 반영 현황 확인 대시보드
* `School.html`: 학교 담당자 피드백 작성 및 제출용 웹 페이지

## 🚀 설치 및 세팅 방법 (Installation & Setup)

### Step 1. Google Drive 및 Sheets 준비
1. **Google Drive 폴더 생성**: 업로드될 이미지가 저장될 새 폴더를 생성하고 URL에서 `Folder ID`를 복사합니다.
2. **Google Sheets 생성**:
   * **[첫 번째 시트]**: A~J열을 다음 헤더로 구성합니다. (데이터가 쌓이는 메인 DB)
     `(제출일시, 위원명, 학교명, 학년, 구분, 검토내용, 첨부사진URL, 학교담당자명, 반영결과, 반영제출일시)`
   * **[두 번째 시트]**: 시트 이름을 반드시 **`학교코드`**로 설정합니다.
     `A열: 나이스번호`, `B열: 학교명` 데이터를 입력해 둡니다.

### Step 2. Apps Script 코드 적용
1. 생성한 스프레드시트에서 `[확장 프로그램] > [Apps Script]`를 클릭합니다.
2. 본 저장소의 파일들(`Code.gs`, `Index.html`, `Admin.html`, `AdminSchool.html`, `School.html`)을 복사하여 동일한 이름으로 생성하고 붙여넣습니다.
  2-1. 변경 사항: `Code.gs`내 `Folder ID`, `Index.html`, `Admin.html`, `AdminSchool.html` 내 암호
3. `Code.gs` 파일 내의 `var folderId = "YOUR_FOLDER_ID_HERE";` 부분을 Step 1에서 복사한 **구글 드라이브 폴더 ID**로 교체합니다.

### Step 3. 배포 및 권한 승인
1. 우측 상단의 `[배포] > [새 배포]`를 클릭합니다.
2. 유형을 `[웹 앱(Web App)]`으로 선택합니다.
3. 설정값을 **실행할 사용자: `나`**, **액세스 권한: `모든 사용자`**로 설정하고 배포합니다.
4. 구글 권한 승인(고급 > 안전하지 않음으로 이동 > 허용)을 완료하면 웹 앱 URL이 발급됩니다.

> ⚠️ **주의:** 코드를 수정한 후에는 반드시 **[배포] > [배포 관리] > 연필 아이콘 > 버전: [새 버전] > [배포]**를 진행해야 변경 사항이 웹에 적용됩니다.

## 🔗 접속 방법 (URL Routing)
단일 웹 앱 URL 끝에 쿼리 파라미터(`?mode=...`)를 붙여 접근을 제어합니다. 파라미터가 없으면 무단 접근으로 간주하여 에러를 띄웁니다.

| 사용자 | 접속 URL 예시 |
|---|---|
| 🚫 외부 무단 접근 | `https://script.google.com/.../exec` (접근 차단) |
| 🧑‍🏫 컨설팅 위원 | `.../exec?mode=expert` |
| 👑 최고 관리자 (입력 현황) | `.../exec?mode=admin` |
| 👑 최고 관리자 (반영 현황) | `.../exec?mode=admin_school` |
| 🏫 학교 담당자 | `.../exec?mode=school` |

*(보안을 위해 `Code.gs`에서 `expert`라는 파라미터 단어를 고유한 단어로 변경하여 사용할 수 있습니다.)*
